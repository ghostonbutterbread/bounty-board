## Contract

With a collaboration store, with or without report autosave, phased inventory, selected lane, selected report index and root-bound report body now use the existing progressive reads. The complete scan still runs separately. Metadata-writer and experimental fixture-publisher configurations retain their previous synchronous behavior; unphased `/api/data` remains the full legacy response. The autosave flag is passed to both selected and complete report classification. Generated navigation remains non-editable.

`capabilities.source_authoritative: false` describes the inventory alone, not the server's general ability to collaborate. Root-bound lane, report-index and report-body responses identify their individual source reads with `source_authoritative: true`; the complete response does likewise in capabilities. This flag denotes a source-scanned response, **not** a promise that every underlying source was readable, nor authority to write by itself: warnings, root-instance checks, report editability, collaborative source binding, and source observation remain independently required. For progressive collaboration the frontend rejects non-authoritative lane/index/body/full responses, and a retained local draft whose report body cannot be verified stays copyable but read-only.
