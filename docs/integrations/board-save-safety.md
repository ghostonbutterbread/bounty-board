## Contract

`/api/data` report entries and `/api/report` expose `editable: true` only when source autosave is opted in, the Markdown is readable, and it is not a BBH navigation/link stub or exact seeded placeholder. Otherwise `editable` is false. Registered/unregistered normal Markdown, generated finding reports, and evidence remain eligible; a marker takes precedence over recorded ownership. Unavailable contents are not editable. `report_edit` remains false (legacy direct PUT is disabled); `report_autosave` signals the opt-in collaboration writer. These are observations, not permissions guaranteed against subsequent file changes. Collaboration POST, including explicit reconciliation, returns 403 `generated_navigation_not_editable` with an actionable message for a currently identified navigation source. The publisher independently checks the source and checks again just before exchange, including source inode identity.

Classifier follows the BBH `agents/report_paths.py` semantics reviewed from the local `bug_bounty_harness-ip-retry-continuation` checkout: exact generated navigation and category-link markers anywhere in content, plus `is_seeded_report_index` exact heading/path matches. Finding-report markers remain editable. No blanket `index.md` or evidence exclusion. The previous source paths and descriptor-relative safeguards are unchanged.

A sweep checks at most 64 retained operations per call. A completed multi-call sweep grants one next POST a bounded zero-scan continuation only if no newer publication operation exists, checked while holding the same store-wide observation lock through submission/publication. A competing process's new operation invalidates the continuation and initiates another bounded sweep; `503 retained_scan_backlog` means retain the draft and retry the identical request ID and body. Pending/uncertain operations remain `uncertain` and prevent publication. Continuations are process-local and lost on restart, which merely restarts a bounded sweep. After a completed write, future requests start another sweep, so changes to earlier retained inodes remain discoverable.
